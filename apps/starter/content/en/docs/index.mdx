This is your new documentation site. Edit `content/docs/index.mdx` to change this page, and add more
`.mdx` files next to it: every file is a page, every folder is a section of the sidebar.

<Callout type="info" title="Components need no import">
  `Callout`, `Tabs`, `Steps`, `Cards`, `TypeTable` and more are available in every page.
</Callout>

## Add a page

<Steps>
<Step>Create `content/docs/my-page.mdx` with a `title` in its header.</Step>
<Step>List it in `content/docs/meta.json` (or leave `pages` out to list everything).</Step>
<Step>Save. The page appears in the sidebar at once.</Step>
</Steps>

## Your own components

Put a React component in `custom/components/`, for example `Since.tsx`, and use `<Since />` in any
page. The file name is the tag, and there is nothing to register.
