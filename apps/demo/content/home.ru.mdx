## Один тип, от отправителя до воркера

Эта страница написана на MDX (`content/home.ru.mdx`), поэтому на ней доступно всё, что есть на странице документации: блоки кода, врезки и ваши компоненты.

```ts title="jobs/send-email.ts"
import { defineJob } from "lattice";

export const sendEmail = defineJob<{ to: string; subject: string }>("send-email");
```
