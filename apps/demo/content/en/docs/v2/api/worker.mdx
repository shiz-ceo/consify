---
title: createWorker
description: Process jobs from a queue
---

```ts
function createWorker<Data>(
  queue: Queue<Data>,
  handler: (job: Job<Data>) => Promise<void>,
  options?: WorkerOptions,
): Worker;
```

<TypeTable
  type={{

  }}
/>

The returned `Worker` has a single method, `close()`, which stops taking jobs and waits for active ones.

> [!WARNING]
> If `handler` never settles, `close()` never resolves. Use timeouts inside long handlers.
