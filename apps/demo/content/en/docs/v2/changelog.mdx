Lattice follows [semantic versioning](https://semver.org). Breaking changes only happen in major versions and always come with a [migration guide](./migration.mdx).

<Release version="2.3.0" date="2026-10-01">
  <Badge variant="beta">beta</Badge>

  - **Added** rate limit groups: several queues can share one limit. See [Scheduling](./guides/scheduling.mdx).
  - **Added** `queue.pause()` and `queue.resume()`.
  - **Changed** the default `concurrency` of a worker is now `1` for every backend.
</Release>

<Release version="2.2.1" date="2026-09-18">
  - **Fixed** `worker.close()` no longer resolves before the last active job reported its result.
  - **Fixed** delayed jobs added right at midnight UTC ran one hour late in some time zones.
</Release>

<Release version="2.2.0" date="2026-09-10">
  - **Added** a timeout option for `worker.close()`.
  - **Fixed** a race when two workers took the same delayed job.
  - **Deprecated** the `lattice/legacy` entry point, it will be removed in 3.0.
</Release>

<Release version="2.1.0" date="2026-08-30">
  - **Added** recurring jobs with `schedule()` <Since version="2.1" />.
  - **Added** OpenTelemetry events, see [Observability](./guides/advanced/observability.mdx).
  - **Improved** the Redis backend uses one connection per process instead of one per queue.
</Release>

<Release version="2.0.0" date="2026-07-01">
  <Badge variant="danger">breaking</Badge>

  - **Breaking** typed queues with `createQueue<Data>()`. See [Migrating from v1](./migration.mdx).
  - **Breaking** `attempts` was renamed to `retries` and now counts retries, not tries.
  - **Breaking** Node.js 20 or newer is required.
  - **Added** the [HTTP API](./api/rest.mdx).
</Release>
