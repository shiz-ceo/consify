description: Everything the lattice package exports

| Export | Kind | Description |
| ------ | ---- | ----------- |
| [`createQueue`](./create-queue.mdx) | function | Creates a typed queue |
| [`Queue`](./queue.mdx) | interface | Add jobs and read statistics |
| [`createWorker`](./worker.mdx) | function | Starts processing a queue |
| [`LatticeError`](./errors.mdx) | class | Errors raised by Lattice |

The package also exposes an [HTTP API](./rest.mdx) for languages other than TypeScript.
