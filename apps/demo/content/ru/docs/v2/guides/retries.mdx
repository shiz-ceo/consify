---
title: Повторы и backoff
description: Сделайте сбои дешёвыми
---

Упавшая задача повторяется до `retries` раз. Между попытками Lattice ждёт с **экспоненциальной задержкой и случайным разбросом**:

$$
\text{delay}(n) = \min\left(d_{max},\; d_0 \cdot 2^{\,n-1}\right) + \text{jitter}
$$

где $d_0$ — базовая задержка, $n$ — номер попытки, $d_{max}$ ограничивает ожидание.

```ts twoslash
import { createQueue } from "lattice";

const payments = createQueue<{ orderId: string }>("payments");

await payments.add({ orderId: "o_42" }, { retries: 5, priority: "high" });
```

## Окончательные сбои

Некоторые ошибки не исправятся никогда, например ошибка валидации. Для таких задач ставьте `retries: 0` или перехватывайте ошибку и завершайте задачу сами.

```diff
- await queue.add(data, { retries: 3 });
+ await queue.add(data, { retries: 0 }); // не повторять ошибки валидации
```

## Очередь недоставленных

После последней попытки задача переходит в `<очередь>:dead`. Изучите её, исправьте причину и верните задачу.

<Callout type="warn" title="Следите за размером">
  Такие очереди растут незаметно. Настройте оповещение, когда `stats().failed` постоянно увеличивается.
</Callout>
