Lattice следует [семантическому версионированию](https://semver.org/lang/ru/). Ломающие изменения бывают только в мажорных версиях и всегда сопровождаются [руководством по миграции](./migration.mdx).

<Release version="2.3.0" date="2026-10-01">
  <Badge variant="beta">beta</Badge>

  - **Добавлено** группы ограничений частоты: несколько очередей могут делить один лимит.
  - **Добавлено** `queue.pause()` и `queue.resume()`.
  - **Изменено** параллелизм воркера по умолчанию теперь `1` для любого бэкенда.
</Release>

<Release version="2.2.1" date="2026-09-18">
  - **Исправлено** `worker.close()` больше не завершается раньше, чем последняя активная задача сообщила результат.
  - **Исправлено** отложенные задачи, добавленные ровно в полночь UTC, в некоторых часовых поясах запускались на час позже.
</Release>

<Release version="2.2.0" date="2026-09-10">
  - **Добавлено** параметр таймаута для `worker.close()`.
  - **Исправлено** гонка, при которой два воркера брали одну отложенную задачу.
  - **Устарело** точка входа `lattice/legacy`, её удалят в 3.0.
</Release>

<Release version="2.1.0" date="2026-08-30">
  - **Добавлено** повторяющиеся задачи через `schedule()` <Since version="2.1" />.
  - **Добавлено** события OpenTelemetry.
  - **Улучшено** бэкенд Redis использует одно соединение на процесс вместо одного на очередь.
</Release>

<Release version="2.0.0" date="2026-07-01">
  <Badge variant="danger">breaking</Badge>

  - **Ломающее** типизированные очереди через `createQueue<Data>()`. См. [миграцию с v1](./migration.mdx).
  - **Ломающее** `attempts` переименован в `retries` и считает повторы, а не попытки.
  - **Ломающее** требуется Node.js 20 или новее.
  - **Добавлено** HTTP API.
</Release>
