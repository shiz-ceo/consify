---
title: Задачи
description: Что такое задача и как проверяется её тип
---

Задача — это данные, которые вы передаёте в `queue.add`, с добавленным идентификатором и служебной информацией.

```ts twoslash
import type { Job } from "lattice";

declare const job: Job<{ userId: string }>;

job.data.userId;
//   ^?
job.attempts;
//  ^?
```

## Идентичность

У каждой задачи есть уникальный `id`. Чтобы сделать задачу **идемпотентной**, выводите id из своих данных: тогда повторное добавление сохранит только одну копию.

> [!IMPORTANT]
> Данные задачи должны сериализоваться. Функции, экземпляры классов и циклические структуры постоянные бэкенды сохранить не могут.
