title: Plugins

A plugin is one object. Every field is optional:

```ts title="custom/plugins/my-plugin.ts"
import { definePlugin } from "@consify/core/plugins";

export const myPlugin = definePlugin({
  name: "my-plugin",
  remark: [],     // Markdown syntax tree
  rehype: [],     // HTML syntax tree
  shiki: {        // code blocks
    transformers: [],
    langs: [],
  },
  components: {}, // MDX components
  messages: {},   // UI strings per language
});
```

```ts title="docs.config.ts"
import { myPlugin } from "./custom/plugins/my-plugin.ts";

export default defineConfig({
  site: { name: "Docs" },
  mdx: { plugins: [myPlugin] },
});
```

Plugins go in `mdx.plugins`. They run in the order they are listed, after the built-in behavior. Names must be unique.

## What each field is for

| Field | Use it to |
| --- | --- |
| `remark` | Change Markdown before it becomes HTML: new syntax, automatic components |
| `rehype` | Change the HTML tree: add attributes, wrap elements |
| `shiki.transformers` | Change how code is rendered: line decorations, badges |
| `shiki.langs` | Preload a language for highlighting |
| `components` | Add MDX components together with the plugin that needs them |
| `messages` | UI strings of the plugin per language; `custom/locales` and `i18n.messages` win over them |

<Callout type="info">
  Shiki and remark/rehype plugins come from their own ecosystems. Any plugin that works with
  `unified` or Shiki works here.
</Callout>
