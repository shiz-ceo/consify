## Video and images

`<Video src="..." title="..." />` embeds a video with controls. Every image, GIF and video gets a thin border that takes the tint of the media under it. Use `<img plain />` to leave one without.

## Blog components

The `@consify/blog` package adds `Authors`, `Expand`, `PR`, `Benchmark`, `Figure`, `Embed` and `CTA`. They are available once `blog()` is in `features`. Any feature can bring MDX components this way. See [Blog components](/docs/v0/blog/components).

## Your own

Drop a file into `custom/components/`: `custom/components/Since.tsx` becomes `<Since />`. Components from a package go into `mdx.components` of the config. See [Custom components](/docs/v0/customizing/custom-components).
