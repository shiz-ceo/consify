The blog is a section of the site with its own list, article pages, RSS feed and social images. It comes as the `@consify/blog` package and is off until `blog()` is in the `features` of the config.

<Steps>
<Step>

Install the package:

```bash
bun add @consify/blog
```

</Step>
<Step>

Add the feature. Categories and authors are defined here, so a typo in a post is caught:

```ts title="docs.config.ts"
import { defineConfig } from "@consify/core";
import { blog } from "@consify/blog";

export default defineConfig({
  site: { name: "My docs" },
  features: [
    blog({
      categories: [{ id: "releases", label: "Releases" }],
      authors: { ada: { name: "Ada Novak", role: "Maintainer" } },
    }),
  ],
});
```

</Step>
<Step>

Write a post:

```mdx title="content/en/blog/hello.mdx"
---
title: Hello
description: The first post
date: 2026-09-01
categories: [releases]
authors: [ada]
---

The text of the post.
```

</Step>
<Step>

Open `/en/blog`. A link to it appears in the header in the order of `features`, unless `header.links` sets another.

</Step>
</Steps>

## What the reader gets

- **A list** with category pills, a search box that looks at titles, tags and authors, tags to pick from, a large first row and numbered pages.
- **A post page** with the cover, the authors, the date, reading time, a table of contents that follows the reader, share buttons and related posts.
- **An RSS feed** at `/{lang}/blog/rss.xml`, and a social image for every post at `/{lang}/blog/og/<slug>.png`.
- **Search**: on the blog pages, Cmd/Ctrl+K searches the posts.
- **Translations** of a post with a fallback to the default language.

<Callout type="info" title="No leaks">
  A draft or a post dated in the future is not published at all. It is not in the list, the search,
  the feed or the build output, not merely hidden. `CONSIFY_DRAFTS=1` shows them while you write. See [Drafts and scheduled posts](/docs/v0/blog/drafts-and-scheduling).
</Callout>

Settings of the blog are on the [configuration page](/docs/v0/configuration/blog).
