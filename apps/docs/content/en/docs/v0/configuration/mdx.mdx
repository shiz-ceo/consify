title: MDX
description: Math, twoslash, components and plugins of every .mdx file

`mdx` holds everything about `.mdx` files: the docs, the blog posts, the front page and the content of your own features. It applies to the whole site.

```ts title="docs.config.ts"
import { defineConfig } from "@consify/core";
import { Chart } from "./custom/chart.tsx";
import { externalLinks } from "./custom/plugins/external-links.ts";

export default defineConfig({
  site: { name: "My docs" },
  mdx: {
    math: true,
    twoslash: { compilerOptions: { strict: true } },
    components: { Chart },
    plugins: [externalLinks],
  },
});
```

Every option is optional.

  type={{

/>

Turning `math` or `twoslash` off also removes them from the compilation of the pages, which makes it a little faster.

## Components

A file in `custom/components/` is a component by its file name: `custom/components/Chart.tsx` is `<Chart />` in every `.mdx` file. Use `mdx.components` for a component that lives elsewhere, or under another name. See [Custom components](/docs/v0/customizing/custom-components).

## Search

Search has no switch here. Every section with content (the docs, the blog, your own) has its own search, see [Home, header and footer](/docs/v0/configuration/layout).
