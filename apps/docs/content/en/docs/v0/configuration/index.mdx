All settings live in `docs.config.ts`. Wrap them in `defineConfig` for editor hints:

```ts title="docs.config.ts"
import { defineConfig } from "@consify/core";
import { docs } from "@consify/docs";

export default defineConfig({
  site: { name: "My docs" },
  features: [docs()],
});
```

Only `site.name` is required. Everything else has a default.

The core (`@consify/core`) gives the frame: config, layout, theme, search and the build. The sections of the site are *features*, listed in `features`: the documentation (`@consify/docs`), the blog (`@consify/blog`), the API reference (`@consify/api-reference`) and your own, made with `defineFeature`. The options of a packaged feature are passed to its function (`docs({...})`, `blog({...})`, `apiReference({...})`) and are checked when it is called. A `versions`, `blog` or `openapi` key at the top level is an unknown key.

## Validation

The config is validated when the dev server or a build starts. Unknown keys are errors (a typo in an option name is caught, not ignored), and messages name the path:

```text
Invalid docs.config:
✖ Unrecognized key: "blogg"
✖ i18n.defaultLanguage: defaultLanguage "de" must be one of: en, ru
```

## Sections

| Key | What it configures |
| --- | --- |
| [`site`](/docs/v0/configuration/site) | Name, description, URL, favicon, GitHub repository |
| [`i18n`](/docs/v0/configuration/languages) | Languages, their names, UI strings |
| [`theme`](/docs/v0/configuration/theme) | [Presets and brand color](/docs/v0/configuration/themes), colors, radius, fonts |
| [`head`](/docs/v0/configuration/head) | Meta tags, links and scripts (analytics) in the `<head>` of every page |
| [`banner`](/docs/v0/configuration/banner) | A closable announcement above the header |
| [`header`, `footer`, `slots`](/docs/v0/configuration/layout) | The frame around every page. The links of the header and the footer: [Header and footer links](/docs/v0/configuration/navigation) |
| `features` | The sections of the site: [the docs](/docs/v0/configuration/docs) (with [versions](/docs/v0/configuration/versions)), [the blog](/docs/v0/configuration/blog), [the API reference](/docs/v0/configuration/api-reference), or [your own](/docs/v0/features) |
| [`mdx`](/docs/v0/configuration/mdx) | Math, `twoslash`, MDX components and [plugins](/docs/v0/customizing/plugins) |
| `deploy` | [Server or static](/docs/v0/deployment), `basePath` |

The front page is not a key: it is `content/<language>/home.mdx` (see [Home, header and footer](/docs/v0/configuration/layout)).

The complete list with types and defaults is in the [configuration reference](/docs/v0/reference/config).
