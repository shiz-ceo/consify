The documentation section is a feature, like the blog: it is on when `docs()` is in the `features` list of the config. Writing pages is covered in [Writing](/docs/v0/writing).

## Install

```bash
bun add @consify/docs
```

Update it together with the core (see [Updating](/docs/v0/concepts/updating)).

## Options

```ts title="docs.config.ts"
import { defineConfig } from "@consify/core";
import { docs } from "@consify/docs";

export default defineConfig({
  site: { name: "My docs", github: { repo: "owner/name", branch: "main" } },
  features: [
    docs({
      versions: {
        list: [
          { id: "v2", label: "v2 (latest)", status: "latest" },
          { id: "v1", status: "deprecated" },
        ],
        default: "v2",
      },
      toc: true,
      breadcrumbs: true,
      pagination: true,
      llmsTxt: true,
      og: true,
      linkPreview: true,
      editOnGithub: { contentDir: "apps/docs/content" },
    }),
  ],
});
```

Every option is optional.

The options are checked when `docs()` is called, so a typo in an option name stops the start with a message that names `docs()` and the option.

## Addresses

| Address | What it is |
| --- | --- |
| `/{lang}/docs/...` | The pages, one per `.mdx` file of `content/<language>/docs/` |
| `/{lang}/docs` | Redirects to the default version when the docs have versions |
| `/{lang}/docs/search.json` | The search of the docs |
| `/{lang}/docs/llms.txt`, `llms-full.txt` | The docs as plain text (`llmsTxt`) |
| `/{lang}/docs/og/<page>.png` | The social image of a page (`og`) |
| `/{lang}/docs/_previews.json` | The text of the link cards: a title and a first paragraph of every page and heading (`linkPreview`) |

## Link cards

When the pointer is over a link to another page of the docs in the text of a page, a card shows the title and the description of that page. A link to a heading (`./retries.mdx#permanent-failures`) shows the heading, its first paragraph and the page it is on. A page without a description is told by its first paragraph.

Only the links in the text of the page have cards: not the sidebar, the headings, the tiles (`<Card>`), links to other sites, downloads and links that open in a new tab. A link to a page that is not in the docs has none. A touch screen has no hover, so it has no cards, and the keyboard gets the card when the link is focused (Escape closes it).

The cards are one file per language, `/{lang}/docs/_previews.json`, made from the text of the files without compiling them. The browser loads it once, when the pointer is first over such a link: about 20 KB gzipped for 60 pages, 300 KB for 250 pages with many headings. Turn it off with `linkPreview: false`.

## A second section

`docs()` can be listed more than once. Each call with its own `id` is a separate section, with its own folder, sidebar, search and link in the header:

```ts title="docs.config.ts"
features: [docs(), docs({ id: "guides", title: { en: "Guides", ru: "Руководства" } })],
```

The second section lives in `content/<language>/guides/` and opens at `/{lang}/guides`.
