## features

The sections of the site, in the order of their links in the header: `docs()` from `@consify/docs` ([options](/docs/v0/configuration/docs)), `blog()` from `@consify/blog` ([options](/docs/v0/configuration/blog)), `apiReference()` from `@consify/api-reference` ([options](/docs/v0/configuration/api-reference)), or your own, made with [`defineFeature`](/docs/v0/features). Default `[]`. Two features cannot have the same `id` or address.

```ts title="docs.config.ts"
features: [docs(), blog(), apiReference({ input: "./openapi.json" }), status],
```

Search is on for every feature with content; there is no switch for it.

## footer

`{ description?, columns?, social?, legal? }`, or `false` to remove it. `columns` is `{ title, links[] }[]` with [link items](/docs/v0/configuration/navigation). Without `columns` the footer lists the main places of the features.

## slots

`{ header?, headerEnd?, footer? }`: React components that replace parts of the site. `custom/header.tsx` and `custom/footer.tsx` do the same; the config wins when both exist. See [Slots](/docs/v0/customizing/slots).

## docs options

Passed to `docs()` from `@consify/docs`, in `features`. All are optional. See [Docs](/docs/v0/configuration/docs).

```ts title="docs.config.ts"
import { docs } from "@consify/docs";
```
