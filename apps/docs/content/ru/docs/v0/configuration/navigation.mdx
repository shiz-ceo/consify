---
title: Ссылки шапки и подвала
description: Выберите ссылки шапки и подвала и сгруппируйте их в выпадающие меню
---

Раздел (документация, блог, справочник API, ваш собственный) только **предлагает** ссылки. Сайт сам выбирает, какие из них попадут в шапку и подвал, в каком порядке и под какими названиями.

## Каталог [#the-catalog]

У каждой ссылки, которую предлагает раздел, есть `id`: `id` фичи для её главного места и `<id>:<имя>` для остальных.

| Id | Адрес | По умолчанию |
| --- | --- | --- |
| `docs` | Документация, версия по умолчанию | шапка, подвал |
| `docs:llms` | `/{lang}/docs/llms.txt` | |
| `blog` | Блог | шапка, подвал |
| `blog:rss` | Лента RSS | |
| `api` | Справочник API | шапка, подвал |

[Ваша собственная фича](/docs/v0/features) добавляет свои id: своё главное место, если у неё есть `title`, `<id>:llms`, если у её контента включён `llms`, и то, что возвращают её `links`. Каталог вашего сайта:

```bash
consify links        # the default language
consify links ru
```

Команда печатает id, название и адрес каждой ссылки и отмечает те, что по умолчанию стоят в шапке.

## Шапка [#header]

Без `header.links` в шапке главное место каждого раздела с заголовком, в порядке `features`. Чтобы выбрать самим:

```ts title="docs.config.ts"
header: {
  links: [
    "docs",
    { id: "blog", title: { en: "News", ru: "Новости" } },
    {
      title: { en: "Developers", ru: "Разработчикам" },
      items: [
        "api",
        "status",
        "docs:llms",
        {
          title: "GitHub",
          description: { en: "Source code and issues", ru: "Исходный код и задачи" },
          url: "https://github.com/example/lattice",
        },
      ],
    },
  ],
},
```

## Элементы ссылок [#link-items]

Шапка и подвал принимают элементы одного формата. Ссылка бывает одной из трёх:

- **Id** из каталога: `"docs"`.
- **Id с заменой полей**: `{ id: "blog", title: "News" }`.
- **Свой адрес**: `{ title, url }`.

Названия и описания из каталога переводятся строками интерфейса раздела, как и остальные строки сайта (см. [Языки](/docs/v0/configuration/languages)).

## Выпадающие меню [#drop-down-menus]

Элемент с `items` вместо `id` или `url` — это меню: название, необязательное описание и список ссылок. В шапке оно показывается выпадающим списком с описанием под каждым названием, а мобильное меню показывает тот же список. В меню бывают только ссылки, вложенных меню нет.

## Подвал [#footer]

`footer.columns[].links` принимает те же элементы, кроме меню:

```ts title="docs.config.ts"
footer: {
  columns: [
    { title: "Product", links: ["docs", "blog", "blog:rss"] },
    { title: { en: "Community", ru: "Сообщество" }, links: [{ title: "GitHub", url: "https://github.com/example/lattice" }] },
  ],
},
```

Без `footer.columns` в подвале одна колонка с главными местами разделов и ссылкой на GitHub.

## Id в других местах [#ids-elsewhere]

Id работает везде, где разбирается ссылка: в `href` кнопок главной страницы (`href: "blog"`) и в ссылках подвала.

## Ошибки [#errors]

Id, которого нет в каталоге, останавливает запуск:

```text
unknown link "blgo" (available: docs, docs:llms, blog, blog:rss, ...)
```

Команда `consify links` покажет доступные id.
