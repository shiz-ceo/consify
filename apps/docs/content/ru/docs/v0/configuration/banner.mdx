---
title: Баннер
description: Объявление над шапкой, которое читатель может закрыть
---

`banner` показывает объявление над шапкой каждой страницы. Читатель может его закрыть, и выбор запоминается в браузере (`localStorage`). Одновременно показывается один баннер.

```ts title="docs.config.ts"
banner: {
  text: { en: "Lattice 2.0 is out: what changed", ru: "Вышел Lattice 2.0: что изменилось" },
  href: "blog",
  id: "lattice-2",
  variant: "info",
},
```

| Опция | Что делает |
| --- | --- |
| `text` | Текст: строка или объект с текстом для каждого языка |
| `href` | Необязательно. Превращает баннер в ссылку. Идентификатор места, которое предлагает раздел (см. [Ссылки шапки и подвала](/docs/v0/configuration/navigation)), или адрес |
| `id` | Необязательно. Буквы, цифры, `_` и `-`. Читатель, закрывший баннер, не увидит его снова, пока `id` не изменится. Без `id` идентичностью служит текст |
| `variant` | `"info"` (по умолчанию) или `"warning"` |

Чтобы показать новое объявление всем, смените `id` (или текст, если `id` нет).
