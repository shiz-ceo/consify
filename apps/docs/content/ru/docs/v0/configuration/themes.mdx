Две опции `theme` задают внешний вид без записи токенов: `preset` (готовый набор цветов) и `brand` (один цвет для акцента). Обе работают в светлой и тёмной схеме.

```ts title="docs.config.ts"
theme: { preset: "paper", brand: "#0ea5e9", radius: "0.75rem" },
```

## Пресеты [#presets]

`theme.preset` — одно из названий ниже. `neutral` — вид по умолчанию, он ничего не добавляет.

| Пресет | Характер |
| --- | --- |
| `neutral` | Чёрно-белый, по умолчанию |
| `ocean` | Холодные синие тона |
| `forest` | Зелёные тона |
| `sunset` | Тёплые оранжевый и красный |
| `violet` | Фиолетовый |
| `paper` | Тёплая бумага, системный шрифт с засечками, меньший радиус (`0.25rem`) |
| `mono` | Высокий контраст, острые углы (`0.125rem`) |

Пресет задаёт цвета обеих цветовых схем. Одна и та же страница документации в каждом пресете, светлая схема слева и тёмная справа:

## Фирменный цвет [#brand-color]

`theme.brand` — один hex-цвет: `"#0ea5e9"`, `#rgb` или `#rrggbb`. Из него делается акцент для обеих цветовых схем:

- основной цвет: его светлота подбирается с сохранением тона и насыщенности, пока он не читается на фоне страницы с контрастом 4.5:1;
- текст на основном цвете: чёрный или белый, в зависимости от того, какой читается лучше;
- фон при наведении и выделении: цвет страницы, подкрашенный фирменным цветом;
- рамка фокуса.

## Порядок применения [#order-of-application]

Побеждает последнее:

1. `preset`
2. `brand`
3. `colors`, `radius` и `fonts` вашей `theme`

Пресет задаёт основу, фирменный цвет заменяет его акцент, а любой токен, заданный вами, заменяет и то и другое. Пример вверху страницы — вид `paper` с голубым акцентом и более крупным скруглением.

## Доступность [#accessibility]

Каждая текстовая пара каждого пресета и любого фирменного цвета проходит WCAG AA (4.5:1) в обеих цветовых схемах. Числа проверяют модульные тесты, а браузерные тесты измеряют цвета, нарисованные на странице. Подсвеченный код тоже проходит: темы кода — `github-light-high-contrast` и `github-dark-default`.

Токены, которые вы задаёте сами в `colors`, не корректируются. Проверяйте их контраст самостоятельно.

## Ваш бренд за пять минут [#your-brand-in-five-minutes]

Пример: розовый фирменный цвет `#e11d8f` на основе `neutral`.

1. Добавьте цвет:

   ```ts title="docs.config.ts"
   theme: { brand: "#e11d8f" },
   ```

2. Откройте сайт в обеих цветовых схемах. Ссылки, кнопки и рамка фокуса используют фирменный цвет. Последняя пара скриншотов показывает результат на той же странице:

   | Светлая | Тёмная |
   | --- | --- |
   | ![brand, light](/themes/brand-light.jpg) | ![brand, dark](/themes/brand-dark.jpg) |

3. Если нравится основа пресета, добавьте его: `preset: "paper"` меняет поверхности и шрифт, а акцент по-прежнему задаёт фирменный цвет.
4. Задайте радиус и шрифт, если они есть у вашего бренда:

   ```ts title="docs.config.ts"
   theme: {
     brand: "#e11d8f",
     radius: "0.5rem",
     fonts: { sans: "Inter, sans-serif" },
   },
   ```

5. Для всего остального переопределите токен или добавьте свой [CSS](/docs/v0/configuration/theme).
