Раздел документации — фича, как и блог: он включён, когда `docs()` есть в списке `features` конфига. Про написание страниц см. [Написание](/docs/v0/writing).

## Установка [#install]

```bash
bun add @consify/docs
```

Обновляйте его вместе с ядром (см. [Обновление](/docs/v0/concepts/updating)).

## Опции [#options]

```ts title="docs.config.ts"
import { defineConfig } from "@consify/core";
import { docs } from "@consify/docs";

export default defineConfig({
  site: { name: "My docs", github: { repo: "owner/name", branch: "main" } },
  features: [
    docs({
      versions: {
        list: [
          { id: "v2", label: "v2 (latest)", status: "latest" },
          { id: "v1", status: "deprecated" },
        ],
        default: "v2",
      },
      toc: true,
      breadcrumbs: true,
      pagination: true,
      llmsTxt: true,
      og: true,
      linkPreview: true,
      editOnGithub: { contentDir: "apps/docs/content" },
    }),
  ],
});
```

Все опции необязательны.

Опции проверяются в момент вызова `docs()`, поэтому опечатка в названии опции останавливает запуск с сообщением, где указаны `docs()` и опция.

## Адреса [#addresses]

| Адрес | Что это |
| --- | --- |
| `/{lang}/docs/...` | Страницы, по одной на каждый файл `.mdx` в `content/<язык>/docs/` |
| `/{lang}/docs` | Перенаправляет на версию по умолчанию, если у документации есть версии |
| `/{lang}/docs/search.json` | Поиск по документации |
| `/{lang}/docs/llms.txt`, `llms-full.txt` | Документация простым текстом (`llmsTxt`) |
| `/{lang}/docs/og/<page>.png` | Изображение страницы для соцсетей (`og`) |
| `/{lang}/docs/_previews.json` | Тексты карточек ссылок: заголовок и первый абзац каждой страницы и заголовка (`linkPreview`) |

## Карточки ссылок [#link-cards]

Когда курсор над ссылкой на другую страницу документации в тексте страницы, карточка показывает заголовок и описание этой страницы. У ссылки на заголовок (`./retries.mdx#permanent-failures`) карточка показывает заголовок, его первый абзац и страницу, на которой он находится. У страницы без описания вместо него первый абзац.

Карточки есть только у ссылок в тексте страницы: не в сайдбаре, не в заголовках, не у плиток (`<Card>`), не у ссылок на другие сайты, скачиваний и ссылок, которые открываются в новой вкладке. У ссылки на страницу, которой нет в документации, карточки нет. На сенсорном экране нет наведения, поэтому там карточек нет, а с клавиатуры карточка появляется, когда ссылка в фокусе (Escape закрывает её).

Карточки это один файл на язык, `/{lang}/docs/_previews.json`, он делается из текста файлов без их компиляции. Браузер загружает его один раз, когда курсор впервые над такой ссылкой: около 20 КБ в gzip на 60 страниц, 300 КБ на 250 страниц с большим числом заголовков. Выключается опцией `linkPreview: false`.

## Второй раздел [#a-second-section]

`docs()` можно указать несколько раз. Каждый вызов со своим `id` — отдельный раздел со своей папкой, боковой панелью, поиском и ссылкой в шапке:

```ts title="docs.config.ts"
features: [docs(), docs({ id: "guides", title: { en: "Guides", ru: "Руководства" } })],
```

Второй раздел лежит в `content/<язык>/guides/` и открывается по адресу `/{lang}/guides`.
