Внешний вид сайта задаётся набором CSS-переменных (дизайн-токенов). По умолчанию это нейтральная чёрно-белая палитра со шрифтом Geist.

Для быстрого старта есть `preset` (готовый вид) и `brand` (один цвет акцента); галерея, порядок применения и гарантия доступности описаны в разделе [Пресеты и фирменный цвет](/docs/v0/configuration/themes). Ниже `colors`, `radius` и `fonts` имеют приоритет над обоими.

```ts title="docs.config.ts"
theme: {
  preset: "ocean",
  brand: "#0ea5e9",
  radius: "0.75rem",
  colors: {
    light: { primary: "oklch(0.55 0.2 260)", "primary-foreground": "white" },
    dark: { primary: "oklch(0.75 0.15 260)" },
  },
  fonts: { sans: "Inter, sans-serif", mono: "'JetBrains Mono', monospace" },
},
```

Названия токенов пишутся без начального `--`. Значения — это CSS, поэтому подойдёт любой синтаксис цвета (`oklch`, `hsl`, hex, `var(...)`). Значения, которые могут закрыть правило или тег (`{`, `}`, `<`, `>`, `;`), отклоняются.

## Токены [#tokens]

| Токен | Для чего используется |
| --- | --- |
| `background`, `foreground` | Фон и текст страницы |
| `card`, `card-foreground` | Карточки и панели |
| `popover`, `popover-foreground` | Меню и диалоги |
| `primary`, `primary-foreground` | Кнопки и акценты |
| `secondary`, `muted`, `accent` | Спокойные поверхности и состояния при наведении |
| `muted-foreground` | Второстепенный текст |
| `border`, `input`, `ring` | Линии и рамки фокуса |

## Свой CSS [#your-own-css]

Для всего, что токенами не сделать, добавьте `custom/theme.css`. Он загружается после темы consify, поэтому его правила имеют приоритет:

```css title="custom/theme.css"
.prose h2 {
  letter-spacing: -0.02em;
}
```
