## URL

В адресе каждой страницы есть язык: `/en/docs/v0/getting-started`, `/ru/docs/v0/getting-started`. Адрес `/` перенаправляет на язык по умолчанию.

## Перевод страниц

У каждого языка своя папка в `content/`: оригинал лежит в `content/en/docs/v0/guide.mdx`, перевод в `content/ru/docs/v0/guide.mdx`, путь тот же. Адреса не переводятся, поэтому страница открывается по `/ru/docs/v0/guide`. `meta.json` работает так же, внутри папки каждого языка. Команда `consify lang add <язык>` готовит новый язык, а `consify lang status` показывает, что ещё не переведено. Подробнее в разделе [Языки и версии](/docs/v0/writing/translations-and-versions).

## Страницы без перевода

Страница, для которой в папке языка нет файла (или у языка вообще нет папки), показывается на языке по умолчанию, поэтому переводить можно постепенно. Как это выглядит, решает `i18n.fallback`:

| Значение | Что видит читатель |
| --- | --- |
| `notice` (по умолчанию) | Исходный текст с пометкой «Эту страницу ещё не перевели», небольшой значок `EN` в сайдбаре и на карточках блога, `lang` документа равен языку текста, каноническим адресом служит адрес оригинала, в sitemap адреса нет |
| `show` | Исходный текст, как будто он переведён, без пометок |
| `hide` | Страницы в этом языке нет: её адрес ведёт на язык по умолчанию, а в сайдбаре, списке блога, ленте и sitemap её тоже нет. Тогда каждому языку нужен свой `meta.json` |

Ссылки на другие языки (`hreflang`) перечисляют только существующие переводы.

`meta.json` в папке языка переводит заголовок папки и порядок страниц. Всё, что не является текстом (`root`, `icon`, `defaultOpen`, `collapsible`), берётся из `meta.json` языка по умолчанию, поэтому переключатель версий выглядит одинаково в каждом языке. Страница, которую забыли в переведённом списке, добавляется в его конец с предупреждением в консоли и никогда не пропадает из сайдбара.

## Строки интерфейса

consify поставляет английские и русские строки для того, что рисует сам: подвал, страница 404, уведомления, а также строки доков, блога и других фич. Боковая панель, поиск, оглавление и переключатель темы приходят из Fumadocs, и для русского они тоже переведены. Любой другой язык показывает английский, пока вы его не переведёте.

### Языковой пакет

Чтобы перевести интерфейс на другой язык, создайте для него пакет:

```sh
consify locale de
```

Команда пишет `custom/locales/de.ts` со всеми строками consify, фич сайта и виджетов Fumadocs. Значения это текущий текст, поэтому переводить можно строка за строкой:

```ts title="custom/locales/de.ts"
import { defineLocale } from "@consify/core";

export default defineLocale({
  // the name of the language in the language switcher
  label: "Deutsch",

  messages: {
    // consify
    notFound: "Diese Seite wurde nicht gefunden.",
    backToHome: "Zur Startseite",
    // …
  },

  // the widgets of Fumadocs: sidebar, search, table of contents, theme switcher
  ui: {
    "On this page(table of contents)": "Auf dieser Seite",
    // …
  },
});
```

Затем добавьте `"de"` в `i18n.languages`. Удалите строку, чтобы оставить встроенный текст. Файл `.json` с теми же полями тоже работает. `create-consify` создаёт пустой пакет для каждого языка, для которого у него нет строк, а если у языка сайта нет пакета, консоль сообщит об этом и назовёт команду.

`consify locale de --force` пишет файл заново (без `--force` существующий файл не заменяется).

### Какая строка главнее

От слабой к сильной:

1. Английская, из consify и фич.
2. Строки самого языка, из consify и фич.
3. `messages` [плагинов](/docs/v0/customizing/plugins).
4. Пакет проекта, `custom/locales/<язык>`.
5. `i18n.messages` в `docs.config.ts`, чтобы поменять одну-две строки.

Строка, которой в языке нет, берётся из следующего источника ниже, поэтому пакет может быть неполным.

В `t` фичи её собственные `messages` идут раньше строк других фич и плагинов с тем же ключом, поэтому у двух фич может быть свой `title` без конфликта. Пакет проекта и `i18n.messages` всё равно главнее. Подробнее — в [Строках](/docs/v0/features/strings).

### В своих компонентах

`useMessages()` из `@consify/core/ui` отдаёт строки языка текущей страницы. Фича называет свои ключи:

```tsx
import { useMessages } from "@consify/core/ui";

function Cart() {
  const t = useMessages<{ cart: string }>();
  return <h2>{t.cart}</h2>;
}
```

Строки фичи лежат в её `messages: { en: {...}, ru: {...} }`, строки плагина в `messages` плагина. Обе группы попадают в пакет, который создаёт `consify locale`. Страница фичи получает те же строки как `t`: `t("cart")`, а `t("hello", { name })` подставляет `{name}` в строку.
