В `mdx` собрано всё, что касается файлов `.mdx`: документации, постов блога, главной страницы и контента ваших собственных фич. Настройки действуют на весь сайт.

```ts title="docs.config.ts"
import { defineConfig } from "@consify/core";
import { Chart } from "./custom/chart.tsx";
import { externalLinks } from "./custom/plugins/external-links.ts";

export default defineConfig({
  site: { name: "My docs" },
  mdx: {
    math: true,
    twoslash: { compilerOptions: { strict: true } },
    components: { Chart },
    plugins: [externalLinks],
  },
});
```

Все опции необязательны.

Если отключить `math` или `twoslash`, они не участвуют в компиляции страниц, и она становится чуть быстрее.

## Компоненты [#components]

Файл в `custom/components/` становится компонентом по имени файла: `custom/components/Chart.tsx` это `<Chart />` в каждом файле `.mdx`. `mdx.components` нужен для компонента, который лежит в другом месте или должен называться иначе. См. [Свои компоненты](/docs/v0/customizing/custom-components).

## Поиск [#search]

Переключателя поиска здесь нет. У каждого раздела с контентом (документация, блог, ваш собственный) свой поиск, см. [Главная, шапка и подвал](/docs/v0/configuration/layout).
