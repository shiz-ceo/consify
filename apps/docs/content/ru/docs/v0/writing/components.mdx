## Таблица типов

Поля объекта, по строке на каждое: имя, тип и значение по умолчанию в одной строке, описание под ней. Все строки раскрыты, стрелка справа сворачивает строку до её заголовка. В текстах работает строчный Markdown: `код`, **жирный** и __жирный__, *курсив* и _курсив_, ~~зачёркнутый~~, [ссылки](/docs/v0/writing/components) с подсказкой, `<https://…>` и `\*` для знака, который нужно показать как есть; метки вкладываются друг в друга. Типы и значения по умолчанию подсвечены как код (встроенные типы, имена типов, строки, числа). Слишком длинный для строки тип кладётся в `typeDescription`: он открывается в подсказке на значке «i» рядом с именем. `title` ставит заголовок над таблицей.

## Видео и изображения

`<Video src="..." title="..." />` встраивает видео с элементами управления. У каждого изображения, GIF и видео есть тонкая рамка, которая берёт оттенок из медиа под ней. Чтобы оставить без рамки, используйте `<img plain />`.

## Компоненты блога

Пакет `@consify/blog` добавляет `Authors`, `Expand`, `PR`, `Benchmark`, `Figure`, `Embed` и `CTA`. Они доступны, когда `blog()` есть в `features`. Так MDX-компоненты может принести любой раздел. См. [Компоненты блога](/docs/v0/blog/components).

## Ваши собственные

Положите файл в `custom/components/`: `custom/components/Since.tsx` становится `<Since />`. Компоненты из пакета указываются в `mdx.components` конфига. См. [Собственные компоненты](/docs/v0/customizing/custom-components).
