## Переводы [#translations]

У каждого языка своя папка в `content/`, внутри то же дерево. Перевод лежит по тому же пути и с тем же именем файла, что и оригинал, поэтому адреса не переводятся (`/ru/docs/v0/guides/caching`):

```
content/
├─ en/
│  ├─ home.mdx
│  └─ docs/v0/guides/
│     ├─ meta.json
│     └─ caching.mdx
└─ ru/
   ├─ home.mdx
   └─ docs/v0/guides/
      ├─ meta.json
      └─ caching.mdx
```

- У языка по умолчанию такая же папка, как у остальных. Сайт с одним языком хранит всё в `content/en/`.
- Страница, которой нет в языке, показывается на языке по умолчанию (см. `i18n.fallback` в разделе [Языки](/docs/v0/configuration/languages)).
- `meta.json` в папке языка переводит названия папок и задаёт порядок страниц. `root`, `icon`, `defaultOpen` и `collapsible` берутся из `meta.json` языка по умолчанию.
- Переключатель языка ведёт на ту же страницу на другом языке, если она существует.

## Добавление языка [#adding-a-language]

```bash
consify lang add de
```

Команда создаёт `content/de/` с копиями всех `meta.json` языка по умолчанию, чтобы перевести заголовки, и пишет `custom/locales/de.ts`, пакет строк интерфейса (как `consify locale de`), если язык не встроенный (`en`, `ru`) и пакета ещё нет. Затем она выводит, что делать дальше: добавить код в `i18n.languages` и перевести файлы, сохраняя их путь. Существующие файлы она не перезаписывает, а язык по умолчанию и неверный код отклоняет.

С флагом `--copy` она также копирует все страницы (доки, блог и главную) языка по умолчанию как заготовку.

## Что осталось перевести [#what-is-left-to-translate]

```bash
consify lang status
```

Команда выводит по строке на каждый язык: столбцы соответствуют разделам языка по умолчанию (страницы `переведено/всего`), затем переведённые файлы `meta.json` (`menus`) и строки интерфейса:

```
language      home  docs   blog  menus  interface
en (default)  1/1   33/33  7/7   8/8    -
ru            1/1   11/33  1/7   6/8    built in
de            0/1   0/33   0/7   0/8    none (English)
```

В столбце `interface` стоит `built in`, `custom/locales/<language>.ts: N/M strings` или `none (English)`. Команда также перечисляет файлы, у которых нет оригинала в языке по умолчанию. Укажите язык (`consify lang status de`), чтобы увидеть только его, а `--missing` покажет, каких файлов не хватает, например `content/de/docs/v0/guides/caching.mdx`.

## Версии [#versions]

Версия — это папка верхнего уровня с `"root": "version"`:

```json title="content/en/docs/v0/meta.json"
{ "title": "v0 (latest)", "root": "version", "pages": ["index"] }
```

Добавьте её в `versions.list` в опциях `docs()` (см. [Версии](/docs/v0/configuration/versions)). После этого:

- В боковой панели появляется переключатель версий, который сохраняет страницу, если она есть в обеих версиях.
- У версии со статусом `deprecated` показывается баннер со ссылкой на последнюю.
- Версии и языки сочетаются: `content/ru/docs/v1/guide.mdx` — это русская страница версии 1.

## Добавление новой версии [#adding-a-new-version]

Скопируйте папку (`cp -r v0 v1`), измените заголовок в её `meta.json` и добавьте `{ id: "v1", status: "latest" }` в `versions.list`, а для старой версии установите `stable` или `deprecated`.
