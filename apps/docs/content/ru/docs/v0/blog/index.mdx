---
title: Блог
description: Добавьте блог на свой сайт
---

Блог — это раздел сайта со своим списком, страницами статей, RSS-лентой и социальными картинками. Он приходит отдельным пакетом `@consify/blog` и выключен, пока `blog()` нет в `features` конфига.

<Steps>
<Step>

Установите пакет:

```bash
bun add @consify/blog
```

</Step>
<Step>

Добавьте раздел. Категории и авторы описываются здесь, поэтому опечатка в посте не пройдёт незамеченной:

```ts title="docs.config.ts"
import { defineConfig } from "@consify/core";
import { blog } from "@consify/blog";

export default defineConfig({
  site: { name: "My docs" },
  features: [
    blog({
      categories: [{ id: "releases", label: "Releases" }],
      authors: { ada: { name: "Ada Novak", role: "Maintainer" } },
    }),
  ],
});
```

</Step>
<Step>

Напишите пост:

```mdx title="content/en/blog/hello.mdx"
---
title: Hello
description: The first post
date: 2026-09-01
categories: [releases]
authors: [ada]
---

The text of the post.
```

</Step>
<Step>

Откройте `/en/blog`. Ссылка на блог появится в шапке в порядке списка `features`, если `header.links` не задаёт другой.

</Step>
</Steps>

## Что получает читатель [#what-the-reader-gets]

- **Список** с плашками категорий, поиском по заголовкам, тегам и авторам, тегами для выбора, крупной первой строкой и нумерованными страницами.
- **Страница поста** с обложкой, авторами, датой, временем чтения, оглавлением, которое следует за читателем, кнопками «поделиться» и похожими постами.
- **RSS-лента** по адресу `/{lang}/blog/rss.xml` и социальная картинка для каждого поста по адресу `/{lang}/blog/og/<slug>.png`.
- **Поиск**: на страницах блога Cmd/Ctrl+K ищет по постам.
- **Переводы** поста с откатом на язык по умолчанию.

<Callout type="info" title="Без утечек">
  Черновик или пост с датой в будущем вообще не публикуется. Его нет ни в списке, ни в поиске,
  ни в ленте, ни в результатах сборки — он не просто скрыт. `CONSIFY_DRAFTS=1` показывает такие
  посты, пока вы пишете. См. [Черновики и отложенные посты](/docs/v0/blog/drafts-and-scheduling).
</Callout>

Настройки блога описаны на [странице конфигурации](/docs/v0/configuration/blog).
