Плагин — это один объект. Все поля необязательны:

```ts title="custom/plugins/my-plugin.ts"
import { definePlugin } from "@consify/core/plugins";

export const myPlugin = definePlugin({
  name: "my-plugin",
  remark: [],     // Markdown syntax tree
  rehype: [],     // HTML syntax tree
  shiki: {        // code blocks
    transformers: [],
    langs: [],
  },
  components: {}, // MDX components
  messages: {},   // UI strings per language
});
```

```ts title="docs.config.ts"
import { myPlugin } from "./custom/plugins/my-plugin.ts";

export default defineConfig({
  site: { name: "Docs" },
  mdx: { plugins: [myPlugin] },
});
```

Плагины перечисляются в `mdx.plugins`. Они запускаются в том порядке, в котором перечислены, после встроенного поведения. Имена должны быть уникальными.

## Для чего нужно каждое поле [#what-each-field-is-for]

| Поле | Зачем использовать |
| --- | --- |
| `remark` | Менять Markdown до превращения в HTML: новый синтаксис, автоматические компоненты |
| `rehype` | Менять дерево HTML: добавлять атрибуты, оборачивать элементы |
| `shiki.transformers` | Менять отображение кода: декорации строк, бейджи |
| `shiki.langs` | Заранее загружать язык для подсветки |
| `components` | Добавлять MDX-компоненты вместе с плагином, которому они нужны |
| `messages` | Строки интерфейса плагина по языкам; `custom/locales` и `i18n.messages` сильнее |

<Callout type="info">
  Плагины Shiki и remark/rehype приходят из своих экосистем. Работает любой плагин, совместимый
  с `unified` или Shiki.
</Callout>
