---
title: Кастомизация
description: Способы сделать сайт своим, от самых простых до самых трудоёмких
---

consify рассчитан на то, чтобы его можно было менять без форка. Выбирайте самый простой инструмент:

| Что вам нужно | Что использовать |
| --- | --- |
| Другие цвета, скругления или шрифты | [`theme`](/docs/v0/configuration/theme) в конфигурации |
| Несколько CSS-правил | `custom/theme.css` |
| Новый тег в MDX | [Свои компоненты](/docs/v0/customizing/custom-components) |
| Другое поведение Markdown или блоков кода | [Плагины](/docs/v0/customizing/plugins) в `mdx.plugins` |
| Другая шапка или подвал | [Слоты](/docs/v0/customizing/slots) |
| Другая главная страница | `content/<язык>/home.mdx` или [фича](/docs/v0/features) с `path: ""` |
| Новый раздел со своими страницами | [Фичи](/docs/v0/features) |
| Ещё одна ссылка в шапке или подвале | `header.links` и `footer` в [конфигурации](/docs/v0/configuration/navigation) |
| Скилл для Claude о вашем проекте | [Скиллы для Claude](/docs/v0/customizing/skills) |

Всё это живёт в вашем проекте (`docs.config.ts`, `content/` и `custom/`), поэтому ядро продолжает обновляться.
