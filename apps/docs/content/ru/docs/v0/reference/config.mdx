## features

Разделы сайта в порядке их ссылок в шапке: `docs()` из `@consify/docs` ([опции](/docs/v0/configuration/docs)), `blog()` из `@consify/blog` ([опции](/docs/v0/configuration/blog)), `apiReference()` из `@consify/api-reference` ([опции](/docs/v0/configuration/api-reference)) или ваши собственные, созданные через [`defineFeature`](/docs/v0/features). По умолчанию `[]`. У двух фич не может быть одинакового `id` или адреса.

```ts title="docs.config.ts"
features: [docs(), blog(), apiReference({ input: "./openapi.json" }), status],
```

Поиск включён у каждой фичи с контентом; переключателя для него нет.

## footer

`{ description?, columns?, social?, legal? }` или `false`, чтобы убрать подвал. `columns` — это `{ title, links[] }[]` с [элементами ссылок](/docs/v0/configuration/navigation). Без `columns` подвал перечисляет главные места фич.

## slots

`{ header?, headerEnd?, footer? }`: React-компоненты, которые заменяют части сайта. `custom/header.tsx` и `custom/footer.tsx` делают то же самое; если есть оба варианта, побеждает конфигурация. См. [Слоты](/docs/v0/customizing/slots).
