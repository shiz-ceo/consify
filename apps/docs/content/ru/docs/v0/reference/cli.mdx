---
title: CLI
description: Команда consify
---

```bash
consify <command> [options]
```

| Команда | Что делает |
| --- | --- |
| `dev` | Сервер разработки с горячей перезагрузкой. Порт по умолчанию 5173 |
| `build` | Продакшен-сборка в `build/` |
| `start [--socket <путь>]` | Запускает `build/server/index.js` (нужен `deploy.mode: "server"`). Читает `PORT` (и `HOST`); `--socket <путь>` (или `SOCKET_PATH`) привязывает Unix-сокет вместо порта — см. [Деплой](/docs/v0/deployment) |
| `typegen` | Генерирует типы маршрутов. Используется перед `tsc` |
| `links [язык]` | Печатает каталог ссылок (id, название, адрес) и отмечает те, что по умолчанию стоят в шапке. [Id](/docs/v0/configuration/navigation) указываются в `header.links` и `footer.columns` |
| `locale <язык>` | Пишет `custom/locales/<язык>.ts`, языковой пакет со всеми строками для перевода. `--force` заменяет существующий файл |
| `lang add <язык> [--copy]` | Готовит новый язык: создаёт `content/<язык>/` с копиями всех `meta.json` языка по умолчанию и пишет `custom/locales/<язык>.ts` (если язык не встроенный и пакета ещё нет). С `--copy` копирует также все страницы (доки, блог, главную). Файлы не перезаписывает, язык по умолчанию и неверный код отклоняет |
| `lang status [язык] [--missing]` | По строке на язык: переведённые страницы по разделам, переведённые меню и строки интерфейса. Перечисляет файлы без оригинала. `--missing` показывает, каких файлов языку не хватает. См. [Языки и версии](/docs/v0/writing/translations-and-versions) |
| `deploy [цель]` | Пишет файлы, которые нужны хостингу (workflow, конфиг, Dockerfile, фрагмент nginx...). Без цели, в настоящем терминале — спросит сама. `deploy list` показывает все цели; `deploy check` ищет очевидные проблемы в текущем конфиге (не задан `site.url`, цель не подходит под `deploy.mode`). Существующий файл заменяется только с `--force`. `docker`/`nginx --ci` также пишут workflow GitHub Actions, который проверяет, собирает и деплоит по SSH при каждом пуше. См. [Деплой](/docs/v0/deployment) |
| `doctor` | Проверяет версию Node, что все установленные пакеты `@consify/*` одной версии, и что `docs.config.ts` валиден |
| `docs check` | Проверяет контент: переводы, `meta.json`, фронтматтер. `--languages en,ru`, `--strict` (отсутствующий перевод — ошибка, а не предупреждение) |
| `snippets check` / `snippets find [--min-lines N]` | `check`: каждый `<Snippet id />` страницы называет файл `snippets/`, который есть, и нет файла, который не использует ни одна страница (это и шаг `consify check`, и `consify build`: `--no-snippets-check` его пропускает). `find`: блоки кода, одинаковые на двух страницах и больше (перевод тоже считается), с файлом и тегом сниппета для каждого; `--min-lines` по умолчанию 3. См. [Сниппеты](/docs/v0/writing/snippets) |
| `skill sync` / `skill list` | Собирает скилл каждой включённой фичи (и свои собственные) в `.claude/skills/`, для Claude Code. `list` только показывает, что синхронизировалось бы. Существующей папке, которую `sync` туда не клал, нужен `--force`. См. [Скиллы для Claude](/docs/v0/customizing/skills) |
| `add <спецификатор>` | Устанавливает компонент, плагин, фичу, скилл или фрагмент темы из реестра — `@namespace/name`, короткое имя (реестр по умолчанию) или полный URL. Существующий файл требует `--force` для перезаписи. См. [Реестр](/docs/v0/customizing/registry) |
| `remove <спецификатор>` | Удаляет то, что установил `consify add`. Отказывается, если от этого зависит другая установленная вещь, или если файл был изменён вручную — если не указан `--force` |
| `list` (псевдоним: `registry list`) | Показывает, что установил `consify add`, и отмечает всё изменённое или отсутствующее с момента установки |
| `registry add-source <namespace> <url> [--header "Name: value"] [--default]` | Настраивает приватный или сторонний реестр. `--header` можно повторять; значение может ссылаться на `${ENV_VAR}`. `--default` делает его тем, к которому резолвится короткое имя |
| `registry remove-source <namespace>` | Забывает настроенный реестр. Уже установленные из него вещи не трогает |
| `registry list-sources` | Показывает настроенные реестры (никогда не печатает значение заголовка после подстановки) |
| `--version`, `-v` | Печатает версию каждого установленного пакета `@consify/*` |

Опции после команды передаются инструменту, который её выполняет: `consify dev --port 3000 --host`.

Команда запускает CLI React Router, который идёт в комплекте с consify, поэтому ваш проект не зависит от `@react-router/dev`.

## Скрипты [#scripts]

```json title="package.json"
{
  "scripts": {
    "dev": "consify dev",
    "build": "consify build",
    "start": "consify start",
    "typecheck": "consify typegen && tsc --noEmit"
  }
}
```
