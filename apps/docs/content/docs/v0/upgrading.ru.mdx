```bash
bun update consify
```

consify следует [семантическому версионированию](https://semver.org). До 1.0 минорная версия может содержать ломающие изменения, и каждое из них перечислено здесь.

## Устаревшие опции

Когда опцию переименовывают, старое имя продолжает работать и выводит предупреждение:

```text
consify: `theme.radius` is deprecated since 0.4.0, use `theme.borderRadius`
```

Исправляйте предупреждение в удобном для вас темпе. Старое имя будет удалено в следующей мажорной версии.

## 0.x

Это первая линия версий. Пока переносить нечего. Изменения фиксируются в [журнале изменений](https://github.com/shiz-ceo/consify/blob/main/CHANGELOG.md).
