Без `versions` документация лежит прямо в `content/docs`, а переключателя нет.

## Как выглядят папки

Каждая версия — это папка с `"root": "version"` в её `meta.json`:

```
content/docs/
├─ meta.json            { "pages": ["v2", "v1"] }
├─ v2/
│  ├─ meta.json         { "title": "v2 (latest)", "root": "version", ... }
│  └─ index.mdx
└─ v1/
   ├─ meta.json
   └─ index.mdx
```

`/en/docs` перенаправляет на версию по умолчанию. Переключатель оставляет читателя на той же странице, если она есть в другой версии.
