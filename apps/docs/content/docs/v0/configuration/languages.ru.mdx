## URL

В адресе каждой страницы есть язык: `/en/docs/v0/quickstart`, `/ru/docs/v0/quickstart`. Адрес `/` перенаправляет на язык по умолчанию.

## Перевод страниц

Добавьте рядом файл с кодом языка: `guide.mdx` и `guide.ru.mdx`. Страница без перевода показывается на языке по умолчанию, так что переводить можно постепенно. `meta.json` работает так же (`meta.ru.json`). Подробнее в разделе [Языки и версии](/docs/v0/writing/translations-and-versions).

## Страницы без перевода

Страница, для которой в языке нет файла, показывается на языке по умолчанию, поэтому переводить можно постепенно. Как это выглядит, решает `i18n.fallback`:

| Значение | Что видит читатель |
| --- | --- |
| `notice` (по умолчанию) | Исходный текст с пометкой «Эту страницу ещё не перевели», небольшой значок `EN` в сайдбаре и на карточках блога, `lang` документа равен языку текста, каноническим адресом служит адрес оригинала, в sitemap адреса нет |
| `show` | Исходный текст, как будто он переведён, без пометок |
| `hide` | Страницы в этом языке нет: её адрес ведёт на язык по умолчанию, а в сайдбаре, списке блога, ленте и sitemap её тоже нет. Тогда каждому языку нужен свой `meta.<язык>.json` |

Ссылки на другие языки (`hreflang`) перечисляют только существующие переводы.

`meta.<язык>.json` переводит заголовок папки и порядок страниц. Всё, что не является текстом (`root`, `icon`, `defaultOpen`), берётся из `meta.json`, поэтому переключатель версий выглядит одинаково в каждом языке. Страница, которую забыли в переведённом списке, добавляется в его конец с предупреждением в консоли и никогда не пропадает из сайдбара.

## Строки интерфейса

consify содержит английские и русские строки для того, что рисует сам (блог, подвал, уведомления). Для другого языка используется английский, а любую строку можно переопределить через `messages`. Доступные ключи: `documentation`, `deprecatedVersion`, `goToLatest`, `editOnGithub`, `notFound`, `backToDocs`, `blog`, `allPosts`, `searchPosts`, `filter`, `tags`, `clearFilters`, `noPosts`, `minRead`, `share`, `relatedPosts`, `backToBlog`, `inThisArticle`, `previous`, `next`, `page`, `rss`, `postedBy`, `footerSections`, `footerRights`.

Тексты окна поиска, боковой панели и подобного берутся из Fumadocs и переводятся автоматически, если перевод существует.
