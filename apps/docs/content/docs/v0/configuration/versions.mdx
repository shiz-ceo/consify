---
title: Versions
description: Keep several versions of the documentation
---

```ts title="docs.config.ts"
versions: {
  list: [
    { id: "v2", label: "v2 (latest)", status: "latest" },
    { id: "v1", label: "v1", status: "deprecated" },
  ],
  default: "v2",
},
```

Without `versions` the docs live directly in `content/docs` and there is no switcher.

## How the folders look

Each version is a folder with `"root": "version"` in its `meta.json`:

```
content/docs/
├─ meta.json            { "pages": ["v2", "v1"] }
├─ v2/
│  ├─ meta.json         { "title": "v2 (latest)", "root": "version", ... }
│  └─ index.mdx
└─ v1/
   ├─ meta.json
   └─ index.mdx
```

`/en/docs` redirects to the default version. The switcher keeps the reader on the same page when it exists in the other version.
