title: Справочник API
description: Интерактивная страница API из схемы OpenAPI
---

Справочник API выключен, пока в конфигурации нет блока `openapi`. В этой документации его нет.

```ts title="docs.config.ts"
openapi: { input: "./openapi.json", title: "API" },
```

<TypeTable
  type={{
    input: { description: "Файл схемы OpenAPI относительно корня проекта, URL или список таких значений.", type: "string | string[]", required: true },
    title: { description: "Название ссылки в шапке.", type: "string", default: '"API"' },
  }}
/>

Страница находится по адресу `/{lang}/api` и отображается через [Scalar](https://scalar.com): операции, модели, примеры на нескольких языках и клиент для пробных запросов. Она следует теме сайта (светлой или тёмной), а её поиск открывается из поиска в шапке.

Ничего из этого не загружается, пока читатель не откроет страницу.
