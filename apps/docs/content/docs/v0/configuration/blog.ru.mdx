---
title: Блог
description: Настройки блога
---

Блог включён, если в конфигурации есть блок `blog`. О том, как писать посты, рассказано в разделе [Блог](/docs/v0/blog).

```ts title="docs.config.ts"
blog: {
  title: { en: "Blog", ru: "Блог" },
  description: "News and how-tos.",
  perPage: 12,
  categories: [
    { id: "releases", label: { en: "Releases", ru: "Релизы" } },
    { id: "guides", label: "Guides" },
  ],
  authors: {
    ada: { name: "Ada Novak", role: "Core maintainer", avatar: "/authors/ada.jpg", url: "https://github.com/ada" },
  },
  share: true,
  rss: true,
},
```
