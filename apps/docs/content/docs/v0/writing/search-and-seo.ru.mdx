## Поиск

Поиск включён по умолчанию и охватывает документацию. Откройте его кнопкой в шапке или сочетанием Cmd/Ctrl+K. В режиме `server` он обращается к эндпоинту (`/api/search`); в режиме `static` скачивает файл индекса и ищет прямо в браузере. Отключается через `features.search`.

## Sitemap и robots

`/sitemap.xml` перечисляет все страницы документации и опубликованные записи блога. Для него нужен `site.url`. `/robots.txt` разрешает всё и указывает на sitemap.

## Мета-теги

У каждой страницы есть заголовок, описание, canonical-ссылка, ссылки на переводы (`hreflang`), а также теги Open Graph и Twitter. У записей блога есть ещё теги `article:*`, а в head блога — ссылка на RSS.

## llms.txt

`/{lang}/llms.txt` перечисляет страницы документации, а `/{lang}/llms-full.txt` содержит всю документацию одним простым текстом. Ими могут пользоваться языковые модели и инструменты, читающие документацию. Отключаются через `features.llmsTxt`.

## Картинки для соцсетей

`/{lang}/og/<page>/image.png` — сгенерированная картинка с заголовком страницы. У записей блога есть `/{lang}/blog/<slug>/og.png`, где фоном служит обложка записи. Картинки для документации отключаются через `features.og`.
