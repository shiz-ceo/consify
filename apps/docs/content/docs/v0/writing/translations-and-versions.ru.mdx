## Переводы

Перевод — это соседний файл с кодом языка:

```
guides/
├─ meta.json
├─ meta.ru.json
├─ caching.mdx
└─ caching.ru.mdx
```

- Страница без перевода показывается на языке по умолчанию.
- `meta.ru.json` переводит названия папок и задаёт порядок страниц. Без него используется файл по умолчанию.
- Переключатель языка ведёт на ту же страницу на другом языке, если она существует.

## Версии

Версия — это папка верхнего уровня с `"root": "version"`:

```json title="content/docs/v0/meta.json"
{ "title": "v0 (latest)", "root": "version", "pages": ["index"] }
```

Добавьте её в `versions.list` в конфиге (см. [Версии](/docs/v0/configuration/versions)). После этого:

- В боковой панели появляется переключатель версий, который сохраняет страницу, если она есть в обеих версиях.
- У версии со статусом `deprecated` показывается баннер со ссылкой на последнюю.
- Версии и языки сочетаются: `v1/guide.ru.mdx` — это русская страница версии 1.

## Добавление новой версии

Скопируйте папку (`cp -r v0 v1`), измените заголовок в её `meta.json` и добавьте `{ id: "v1", status: "latest" }` в список, а для старой версии установите `stable` или `deprecated`.
