---
title: CLI
description: Команда docsivi
---

```bash
docsivi <command> [options]
```

| Команда | Что делает |
| --- | --- |
| `dev` | Сервер разработки с горячей перезагрузкой. Порт по умолчанию 5173 |
| `build` | Продакшен-сборка в `build/` |
| `start` | Запускает `build/server/index.js` (нужен `deploy.mode: "server"`) |
| `typegen` | Генерирует типы маршрутов. Используется перед `tsc` |

Опции после команды передаются инструменту, который её выполняет: `docsivi dev --port 3000 --host`, а `docsivi start` читает `PORT`.

Команда запускает CLI React Router, который идёт в комплекте с docsivi, поэтому ваш проект не зависит от `@react-router/dev`.

## Скрипты

```json title="package.json"
{
  "scripts": {
    "dev": "docsivi dev",
    "build": "docsivi build",
    "start": "docsivi start",
    "typecheck": "docsivi typegen && tsc --noEmit"
  }
}
```
