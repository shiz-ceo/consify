---
title: CLI
description: The docsivi command
---

```bash
docsivi <command> [options]
```

| Command | What it does |
| --- | --- |
| `dev` | Development server with hot reload. Default port 5173 |
| `build` | Production build into `build/` |
| `start` | Serves `build/server/index.js` (needs `deploy.mode: "server"`) |
| `typegen` | Generates the route types. Used before `tsc` |

Options after the command go to the tool that runs it: `docsivi dev --port 3000 --host`, `docsivi start` reads `PORT`.

The command runs the React Router CLI that comes with docsivi, so your project does not depend on `@react-router/dev`.

## Scripts

```json title="package.json"
{
  "scripts": {
    "dev": "docsivi dev",
    "build": "docsivi build",
    "start": "docsivi start",
    "typecheck": "docsivi typegen && tsc --noEmit"
  }
}
```
