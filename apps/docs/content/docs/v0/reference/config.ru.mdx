## features

`search`, `toc`, `breadcrumbs`, `pagination`, `llmsTxt`, `og`, `editOnGithub`, `math`, `twoslash`: булевы значения, все по умолчанию `true`. См. [Возможности](/docs/v0/configuration/features).

## Устаревшие опции

Переименованная опция ещё некоторое время продолжает работать и выводит предупреждение с названием замены. См. [Обновление](/docs/v0/upgrading).
