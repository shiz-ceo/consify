`defineConfig` accepts the object below. Unknown keys are errors.

## site

<TypeTable
  type={{
    name: { description: "Name of the site.", type: "string", required: true },
    description: { description: "Description of the site.", type: "string" },
    url: { description: "Public origin.", type: "string (URL)" },
    logo: { description: "Path or URL of the logo.", type: "string" },
    favicon: { description: "Path or URL of the favicon.", type: "string" },
    github: { description: "`{ repo: 'owner/name', branch?: 'main', contentDir?: 'content/docs' }`", type: "object" },
  }}
/>

## i18n

<TypeTable
  type={{
    defaultLanguage: { description: "Fallback language.", type: "string", default: '"en"' },
    languages: { description: "Language codes.", type: "string[]", default: '["en"]' },
    labels: { description: "Names in the switcher.", type: "Record<string, string>", default: "{}" },
    messages: { description: "Overrides of interface strings.", type: "Record<string, Record<string, string>>", default: "{}" },
    fallback: { description: "A page without a translation: `notice`, `show` or `hide`.", type: '"notice" | "show" | "hide"', default: '"notice"' },
  }}
/>

## versions

<TypeTable
  type={{
    list: { description: "`{ id, label?, status?: 'latest' | 'stable' | 'deprecated' }[]`", type: "object[]", default: "[]" },
    default: { description: "Version that `/docs` opens.", type: "string", default: "latest, else first" },
  }}
/>

## features

`search`, `toc`, `breadcrumbs`, `pagination`, `llmsTxt`, `og`, `editOnGithub`, `math`, `twoslash`: booleans, all `true` by default. See [Features](/docs/v0/configuration/features).

## Deprecations

A renamed option keeps working for a while and prints a warning that names the replacement. See [Upgrading](/docs/v0/upgrading).
