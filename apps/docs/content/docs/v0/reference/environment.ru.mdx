---
title: Окружение
description: Переменные, меняющие поведение
---

| Переменная | Эффект |
| --- | --- |
| `CONSIFY_DRAFTS=1` | Добавляет в блог черновики и записи с датой в будущем. Только для написания текстов, никогда для продакшен-сборки |
| `PORT` | Порт для `consify start` |

Остальные переменные (`CONSIFY_DEPLOY_MODE`, `CONSIFY_ROUTES`) consify выставляет сам при запуске, чтобы передать конфиг роутеру. Не задавайте их.
