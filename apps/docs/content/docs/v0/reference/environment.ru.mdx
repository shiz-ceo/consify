---
title: Окружение
description: Переменные, меняющие поведение
---

| Переменная | Эффект |
| --- | --- |
| `DOCSIVI_DRAFTS=1` | Добавляет в блог черновики и записи с датой в будущем. Только для написания текстов, никогда для продакшен-сборки |
| `PORT` | Порт для `docsivi start` |

Остальные переменные (`DOCSIVI_DEPLOY_MODE`, `DOCSIVI_ROUTES`) docsivi выставляет сам при запуске, чтобы передать конфиг роутеру. Не задавайте их.
