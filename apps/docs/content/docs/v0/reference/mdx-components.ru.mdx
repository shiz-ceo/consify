---
title: MDX-компоненты
description: Имена, доступные в каждом .mdx-файле
---

| Компонент | Назначение |
| --- | --- |
| `Callout` | Выделенная заметка (`info`, `warn`, `error`, `success`, `idea`) |
| `Tabs`, `Tab` | Содержимое во вкладках |
| `Steps`, `Step` | Нумерованные шаги |
| `Cards`, `Card` | Карточки, при желании со ссылками |
| `Accordions`, `Accordion` | Сворачиваемые блоки |
| `Files`, `Folder`, `File` | Дерево файлов |
| `TypeTable` | Таблица свойств и типов |
| `Banner` | Баннер во всю ширину страницы |
| `Badge` | Небольшая метка (`new`, `beta`, `deprecated`, `danger`) |
| `Video` | Видео с элементами управления |
| `Mermaid` | Диаграмма (обычно вместо неё используют блок кода `mermaid`) |
| `Authors`, `Expand`, `PR`, `Benchmark`, `Figure`, `Embed`, `CTA` | [Компоненты блога](/docs/v0/blog/components) |
| `Hero`, `Features` | Только на главной странице (`content/home.mdx`) |

Ваши собственные компоненты из `custom/components` и из конфига добавляются в этот список и заменяют встроенный компонент с тем же именем. Плагины тоже могут добавлять компоненты.

Стандартные элементы Markdown (`a`, `img`, `video`, код, таблицы, заголовки) оформляются темой. У `img` и `video` появляется полупрозрачная рамка; `<img plain />` оставляет картинку без неё.
