---
title: Environment
description: Variables that change the behavior
---

| Variable | Effect |
| --- | --- |
| `DOCSIVI_DRAFTS=1` | Includes drafts and posts dated in the future in the blog. For writing only, never for a production build |
| `PORT` | Port of `docsivi start` |

Other variables (`DOCSIVI_DEPLOY_MODE`, `DOCSIVI_ROUTES`) are set by docsivi itself while it starts, to hand the config to the router. Do not set them.
