---
title: Обновление ядра
description: Как проект остаётся актуальным
---

```bash
bun update docsivi
```

Вот и вся процедура. Ваши `docs.config.ts`, `content/` и `custom/` принадлежат вам; пакет никогда в них не пишет. Файлы в `.docsivi/` пересоздаются при каждом запуске.

## Что может сломаться

- **Переименованная опция.** Первый релиз, переименовавший опцию, сохраняет работу старого имени и выводит предупреждение с новым. Ничего не ломается, пока старое имя не удалят в следующей мажорной версии.
- **Новая обязательная настройка.** У новых настроек есть значения по умолчанию, поэтому обновление не делает существующий конфиг некорректным.
- **Ваши компоненты.** Они используют React и токены темы, а те меняются медленно.

Заметки по версиям см. в разделе [Обновление версий](/docs/v0/upgrading).

## Проверка, что всё работает

```bash
bun run typecheck
bun run build
```

Проверка типов охватывает ваш конфиг и ваши компоненты. Сборка падает при некорректном конфиге, неизвестной категории в посте блога или сломанном заголовке поста.
