## Requirements

- [Bun](https://bun.sh) 1.2 or newer.
- Node.js 24 or newer, which runs the build tools under the hood.

## Create a project

The quickest way is the generator. It asks for a name, copies the starter and installs the dependencies:

```bash
bunx create-consify@latest my-docs
cd my-docs
bun run dev
```

Open `http://localhost:5173`. Edit `content/docs/index.mdx` and the page updates.

## Add it to an existing project

```bash
bun add consify react react-dom react-router
bun add -d vite typescript @types/react @types/react-dom @types/node
```

Then create these files.

```ts title="docs.config.ts"
import { defineConfig } from "consify";

export default defineConfig({
  site: { name: "My docs" },
});
```

```ts title="vite.config.ts"
import { consify } from "consify/vite";
import { defineConfig } from "vite";
import config from "./docs.config.ts";

export default defineConfig({ plugins: [consify(config)] });
```

```ts title="react-router.config.ts"
import { defineRouterConfig } from "consify/react-router";
import config from "./docs.config.ts";

export default defineRouterConfig(config);
```

```json title="package.json"
{
  "type": "module",
  "scripts": {
    "dev": "consify dev",
    "build": "consify build",
    "start": "consify start",
    "typecheck": "consify typegen && tsc --noEmit"
  }
}
```

Add a first page, and a `tsconfig.json` (copy the one from the starter):

```mdx title="content/docs/index.mdx"
---
title: Welcome
---

Hello from consify.
```

```json title="content/docs/meta.json"
{ "pages": ["index"] }
```

Add `.consify`, `build` and `.react-router` to `.gitignore`. They are generated.

<Callout type="info" title="Import paths">
  Write the extension in imports of your own files (`./docs.config.ts`). Vite warns about
  extensionless imports in configuration files.
</Callout>

## The commands

| Command | What it does |
| --- | --- |
| `consify dev` | Development server with hot reload |
| `consify build` | Production build (and the pre-rendered pages) |
| `consify start` | Serves a `server` build (`build/server`) |
| `consify typegen` | Generates route types, used by `typecheck` |

Anything after the command is passed on to the underlying tool, for example `consify dev --port 3000`.
