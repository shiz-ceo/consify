---
title: Свои компоненты
description: Используйте собственные React-компоненты в MDX
---

Положите файл в `custom/components/` и используйте его на любой странице. **Ни импорта, ни регистрации не нужно.** Имя файла становится тегом, а экспорт по умолчанию — компонентом.

```tsx title="custom/components/Since.tsx"
export default function Since({ version }: { version: string }) {
  return <span className="rounded-full border px-2 py-0.5 text-xs">since {version}</span>;
}
```

```mdx title="content/docs/v0/guides/caching.mdx"
Recurring jobs <Since version="0.3" />
```

## Правила

- Имя файла начинается с заглавной буквы и является тегом (`Since.tsx` даёт `<Since />`).
- Интерактивные компоненты работают. Добавьте `"use client"`, если этого требует ваш фреймворк, и используйте хуки как обычно.
- Компонент с именем встроенного **заменяет** его. Так можно изменить оформление `Callout` или `Card` в вашем проекте.
- Список пересобирается, пока работает dev-сервер, поэтому новый файл доступен сразу.

<Callout type="warn">
  Не размещайте компонент внутри заголовка. Заголовки попадают в оглавление, которое строится
  вне страницы и не видит компонентов. Поместите компонент в текст под заголовком.
</Callout>

## Из конфигурации

Те же компоненты можно перечислить в конфигурации, что удобно для компонента из пакета:

```ts title="docs.config.ts"
import { Chart } from "my-chart-package";

export default defineConfig({
  site: { name: "Docs" },
  components: { Chart },
});
```

Имена должны начинаться с заглавной буквы (MDX считает теги в нижнем регистре HTML).
