---

Блог — это раздел сайта со своим списком, страницами статей, RSS-лентой и социальными картинками. Он выключен, пока в конфиге нет блока `blog`.

<Steps>
<Step>

Добавьте блок. Категории и авторы описываются здесь, поэтому опечатка в посте не пройдёт незамеченной:

```ts title="docs.config.ts"
blog: {
  categories: [{ id: "releases", label: "Releases" }],
  authors: { ada: { name: "Ada Novak", role: "Maintainer" } },
},
```

</Step>
<Step>

Напишите пост:

```mdx title="content/blog/hello.mdx"
---
title: Hello
description: The first post
date: 2026-09-01
categories: [releases]
authors: [ada]
---

The text of the post.
```

</Step>
<Step>

Откройте `/en/blog`. Ссылка на блог появится в шапке.

</Step>
</Steps>

## Что получает читатель

- **Список** с плашками категорий, поиском по заголовкам, тегам и авторам, тегами для выбора, крупной первой строкой и нумерованными страницами.
- **Страница поста** с обложкой, авторами, датой, временем чтения, оглавлением, которое следует за читателем, кнопками «поделиться» и похожими постами.
- **RSS-лента** по адресу `/{lang}/blog/rss.xml` и социальная картинка для каждого поста.
- **Переводы** поста с откатом на язык по умолчанию.

<Callout type="info" title="Без утечек">
  Черновик или пост с датой в будущем вообще не компилируется. Его нет ни в списке, ни в поиске,
  ни в результатах сборки — он не просто скрыт. См. [Черновики и отложенные посты](/docs/v0/blog/drafts-and-scheduling).
</Callout>

Настройки блога описаны на [странице конфигурации](/docs/v0/configuration/blog).
