## RSS

У каждого языка есть лента по адресу `/{lang}/blog/rss.xml`. Это обычный RSS 2.0 (`application/xml`) с заголовком, описанием, датой, категориями и тегами каждого опубликованного поста. Страницы блога ссылаются на неё в своём head, так что RSS-ридеры находят её сами. Отключается через `blog.rss: false`.

Для абсолютных ссылок в ленте нужен `site.url`.

## Социальные картинки

`/{lang}/blog/<slug>/og.png` — изображение 1200 на 630 с заголовком и датой поверх обложки поста. Если обложка — файл в `public/`, она используется как фон; без неё рисуется градиент, построенный из slug. Страница поста указывает его как своё изображение Open Graph.

## Sitemap

Опубликованные посты и страница списка попадают в `sitemap.xml` для каждого языка.

## Поделиться

На каждом посте есть кнопки для X, LinkedIn и Bluesky и кнопка копирования ссылки. Отключаются через `blog.share: false`.
