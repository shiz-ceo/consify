---
title: Черновики и отложенные посты
description: Неопубликованные посты никогда не попадают в браузер
---

Пост публикуется, если он не черновик и его дата — сегодняшняя или более ранняя.

```mdx
---
title: Coming soon
date: 2030-01-01   # in the future: not published yet
draft: true        # or explicitly a draft
---
```

## Как их не пускают на сайт

Неопубликованные файлы не фильтруются во время работы, они **никогда не компилируются**. Список постов формируется при запуске сайта, и в него попадают только опубликованные файлы. Поэтому черновика нет ни в браузерном бандле, ни в предварительно отрендеренных страницах, ни в поиске, ни в RSS-ленте. Утекать нечему.

Дата проверяется при сборке, поэтому чтобы опубликовать отложенный пост, запустите сборку после его даты. Для статического сайта настройте сборку по расписанию (например, ежедневную в вашем CI).

## Предпросмотр черновиков

Пока вы пишете, задайте `DOCSIVI_DRAFTS=1`, чтобы включить всё:

```bash
DOCSIVI_DRAFTS=1 bun run dev
```

Перезапускайте сервер разработки после добавления или удаления поста, потому что список читается при старте.

<Callout type="warn">
  Никогда не собирайте продакшен-версию с `DOCSIVI_DRAFTS=1`.
</Callout>
