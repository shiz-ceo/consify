## Требования

- [Bun](https://bun.sh) версии 1.2 или новее.
- Node.js версии 24 или новее — на нём под капотом работают инструменты сборки.

## Создание проекта

Быстрее всего воспользоваться генератором. Он спросит название, скопирует стартовый шаблон и установит зависимости:

```bash
bunx create-consify@latest my-docs
cd my-docs
bun run dev
```

Генератор спрашивает папку, название сайта, языки (первый основной) и менеджер пакетов, затем ставит зависимости. Он также добавляет в `.claude/skills/` скилл `consify-docs` для Claude. Чтобы не отвечать на вопросы, передайте ответы параметрами:

```bash
bunx create-consify@latest my-docs --name "My docs" --languages en,ru --pm bun --yes
```

| Параметр | Значение |
| --- | --- |
| `--name <text>` | Название сайта (по умолчанию имя папки) |
| `--languages <list>` | Языки, первый основной (по умолчанию `en`) |
| `--pm <bun\|npm\|pnpm\|yarn>` | Менеджер пакетов (по умолчанию тот, что запустил команду) |
| `--no-install` | Не ставить зависимости |
| `--no-skill` | Не добавлять скилл `consify-docs` |
| `--git` | Выполнить `git init` |
| `-y`, `--yes` | Взять значения по умолчанию, ничего не спрашивать |

Откройте `http://localhost:5173`. Отредактируйте `content/docs/index.mdx`, и страница обновится.

## Добавление в существующий проект

```bash
bun add consify react react-dom react-router
bun add -d vite typescript @types/react @types/react-dom @types/node
```

Затем создайте следующие файлы.

```ts title="docs.config.ts"
import { defineConfig } from "consify";

export default defineConfig({
  site: { name: "My docs" },
});
```

```ts title="vite.config.ts"
import { consify } from "consify/vite";
import { defineConfig } from "vite";
import config from "./docs.config.ts";

export default defineConfig({ plugins: [consify(config)] });
```

```ts title="react-router.config.ts"
import { defineRouterConfig } from "consify/react-router";
import config from "./docs.config.ts";

export default defineRouterConfig(config);
```

```json title="package.json"
{
  "type": "module",
  "scripts": {
    "dev": "consify dev",
    "build": "consify build",
    "start": "consify start",
    "typecheck": "consify typegen && tsc --noEmit"
  }
}
```

Добавьте первую страницу и `tsconfig.json` (скопируйте его из стартового шаблона):

```mdx title="content/docs/index.mdx"
---
title: Welcome
---

Hello from consify.
```

```json title="content/docs/meta.json"
{ "pages": ["index"] }
```

Добавьте `.consify`, `build` и `.react-router` в `.gitignore`. Эти папки генерируются автоматически.

<Callout type="info" title="Пути импорта">
  Указывайте расширение в импортах своих файлов (`./docs.config.ts`). Vite предупреждает об импортах
  без расширения в конфигурационных файлах.
</Callout>

## Команды

| Команда | Что делает |
| --- | --- |
| `consify dev` | Сервер разработки с горячей перезагрузкой |
| `consify build` | Продакшен-сборка (вместе с предварительно отрендеренными страницами) |
| `consify start` | Запускает сборку `server` (`build/server`) |
| `consify typegen` | Генерирует типы маршрутов, которые использует `typecheck` |

Всё, что идёт после команды, передаётся нижележащему инструменту, например `consify dev --port 3000`.
