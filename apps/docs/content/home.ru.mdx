## Проект из трёх файлов

```ts title="docs.config.ts"
import { defineConfig } from "docsivi";

export default defineConfig({
  site: { name: "My project", github: { repo: "me/my-project" } },
  i18n: { languages: ["en", "ru"] },
});
```

```ts title="vite.config.ts"
import { docsivi } from "docsivi/vite";
import { defineConfig } from "vite";
import config from "./docs.config.ts";

export default defineConfig({ plugins: [docsivi(config)] });
```

```ts title="react-router.config.ts"
import { defineRouterConfig } from "docsivi/react-router";
import config from "./docs.config.ts";

export default defineRouterConfig(config);
```

Затем пишите страницы в `content/docs/`, запускайте `bun run dev` — и сайт готов. Прочитайте [Как это работает](/docs/v0/concepts), чтобы узнать, что происходит между этими шагами, или [как был сделан docsivi](/blog/how-docsivi-was-made), чтобы понять, почему он устроен именно так.
