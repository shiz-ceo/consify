# Code of conduct

Be kind and be useful. We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: treat everyone with respect, accept criticism of work without making it personal, no
harassment, no discrimination, no publishing other people's private information.
